# MD 三國志V（中國盜版）ROM 格式

`roms/San Guo Zhi V (China) (Unl).zip`，2MB。位址都是 ROM offset（＝68000 位址）；RAM 寫 `$FFxxxx` 或 `$xxxx`（＝$FF0000 起的 offset）。程式在 `rom.py`。

## 總覽

- 表頭：0x100 只有 `SEGA` 四字，之後就是程式碼（表頭欄位被覆蓋），checksum 不對。MAME 依 0x1F0 選機種，照樣能跑。
- 標題畫面寫「三國志V」、開發標記「SKOB」，文字是繁體中文。
- **沒有壓縮**：劇本資料、字型、頭像、地圖 tile 都是原樣存放；沒有 KOEI LZ。
- 文字不是 Big5／GB2312／SJIS，是自訂字碼（見下）。
- 劇本載入程式 `$924`–`$AAA` 依劇本號 `$FF60E3`（選單預設 3）把各表抄進 RAM。7 個劇本的指標表都是 7 個 long。

## 文字與字型

- 字型：0xAF81C 是 7 個 bank 的指標（long）：0xAF838、0xB1638、…、0xBAC38，每 bank 240 字、每字 32 bytes。
- 字形 16×16 1bpp，存成四個 8×8 象限，順序 TL、TR、BL、BR，每象限 8 bytes（一列一 byte，MSB 在左）。畫面上的字高 14 列。
- 字碼：F0–FB 切換 bank（程式接受到 FB，但只有 7 個 bank），其他 byte 是目前 bank 的字號，FF 結束字串。bank 選擇在同一字串內延續。
- 字的排列是「依第一次出現的順序」：bank 0 開頭就是城名（襄平北平代縣…），沒有標準編碼可對照，只能轉寫。
- 只有 bank 0 的字號 0 是空白；其他 bank 的字號 0 是一般字（bank 1＝蘭、bank 2＝程、bank 3＝刀）。
- 畫面：城名／人名等動態文字畫進 VRAM tile（選君主畫面：城名 `$500`、人名 `$508` 起），每字 2×2 tile，nametable 上 TL TR／BL BR；數字用固定 tile `$7E0 + 2d`（上半）／`+1`（下半）。
- 轉寫：`data/charset.txt`，1680 字中轉寫了 753 字（人名對齊三國志V DOS 中文版 500 人名得 544 字，城市／陣形／戰法／寶物／指令表目視補 209 字，兩者重疊處一致）。其餘 927 字只出現在訊息裡，記為 〓。

### 字串表

格式都是「u16 offset（從表頭算）× N，接著字串」。

| 位址 | 筆數 | 內容 |
|------|------|------|
| 0xAE3C0 | 47 | 城名 |
| 0xAE4D6 | 503 | 人名：0–499 人物，500 憲帝（ROM 寫法，即獻帝）、501–502 民眾 |
| 0xAF1B6 | 12 | 陣形（水陣 雁行 方圓 長蛇 衡軛 鋒矢 偃月 魚鱗 鶴翼 箕形 鉤行 錐行） |
| 0xAF202 | 33 | 戰法（火計 混亂 內鬨 …），最後一筆是「－－」 |
| 0xAF2D8 | 38 | 寶物（兵法二十四篇 … 投石車） |
| 0xAF42C | 28 | 指令（巡察 擔任 交易 …） |
| 0xAF4E2 | 32 | 寶物效果說明（大部分字未轉寫） |
| 0xAF652 | 32 | 訊息（大部分字未轉寫） |
| 0xAF7CA | 13 | 選單（軍事 人事 內政 計謀 外交 沒收 授與 參謀 將軍 太守 免職 賣糧 買糧） |

- 人名順序是筆畫順（丁奉、丁原、于吉…），和三國志V 原作的人物順序不同；人物編號、頭像編號都用這個順序。
- ROM 原有的誤字：董龔（董襲）、兀骨突（兀突骨）、万彧（萬彧）、憲帝（獻帝）、關彝（DOS 版作關彞）。

## 頭像

- 40×48，30 個 4bpp tile 逐列排（5 × 6），每張 960 bytes，**未壓縮**。
- `$395E6`：n < 400 在 0x160000 + 960n，否則 0xE0000 + 960(n − 400)。n＝人物編號（筆畫順）。
- 0–499 是人物；500–535 是另外 36 張（沒有人物記錄引用）；536 那格下半有色號 0（透明）的空洞，不算。
- 色盤固定：0x39800 的 16 色（同時是畫面共用的 CRAM line 0）。
- 來源判斷：和三國志V DOS 中文版（kaodata `san5pk-dos`）同名人物並排，構圖、姿勢、服飾一致，是同一批原畫縮小到 40×48 再用 MD 16 色重新上色。灰階相關係數：同名配對平均 0.54，隨機配對 0.26；497 人中 52% 的「最像的那張」就是同名那張（縮小重繪後細部差很多，所以不是逐 pixel 對應）。

## 選君主地圖

- 40×28 cell 的全畫面 plane B：nametable 0x3D99A（u16 × 1120，含 palette／翻轉位元）。
- tile 1–0x32 在 0x45B20，0x33–0x27D 在 0x5A48C；4 條色盤 0x68C4（128 bytes）。
- 城的節點：0x6BFE，47 words，`(x/8 − 18) << 8 | (y/8 − 17)`（游標 sprite 座標，游標在 `$FF606C`/`$FF606E`，每次移動 16 px），節點是地圖 cell (高 byte + 2, 低 byte + 1) 起的 2×2 cell。滑到節點上時，`$7168` 查這張表得到城號 `$FF6014`。
