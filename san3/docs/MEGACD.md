# Mega-CD 版『三國志III』

KOEI，Mega-CD（系統區 `(C)T-76 1993.FEB`、序號 `GM T-76014 -00`）。映像：`roms/megacd/Sangokushi III (Japan).7z`（Redump，Track 01 MODE1/2352＋音軌）。程式碼在 `cd.py`：`Disc` 繼承 `rom.Rom`，換上光碟的表格位址，沿用卡帶版的解碼器。

和卡帶版相比：

- 多了第 0 個劇本「黄巾の乱」（184 年，選單第一個；卡帶版的 6 個劇本變成 1–6）
- 人物表只改了 2 筆：68 賈範 → **何進**（君主，只在黄巾の乱登場；賈範在 CD 版的劇本都不登場）、476 劉度 換合成臉碼
- 頭像改成未壓縮，合成臉預先合成；有 19 張合成臉重畫了 1–2 個 tile
- 開頭動畫、各劇本開場（`S0`–`S6OPEN.PRG`）、CD 音軌等

## 2. 表格（`SMAIN.PRG` 內的位移；PRG-RAM 位址再加 `$C000`）

| 表 | CD | 卡帶版 | 說明 |
|------|------|------|------|
| 人物 | `0x3421E` | `0x78E94` | 532 × 30 bytes，格式相同；遊戲就地讀取（寫進去的頭像碼直接顯示） |
| 頭像調色盤編號 | `0x3ABCE` | `0x8B7CC` | 307 bytes，內容相同 |
| 頭像調色盤 | `0x3AFB2` | `0x8BBB0` | 內容相同 |
| 事件人物的頭像碼 | `0x3A4DE` | `0x8AF5A` | 10 個，內容相同 |
| 合成臉碼表 | `0x3B8F0` | — | 311 個 BE16，遞增排序 |

人物表差異：

| id | 卡帶版 | CD |
|------|------|------|
| 68 | 賈範（カハン），合成臉 `8C93` | 何進（カシン），合成臉 `8C93`，能力值、生年等全部換掉 |
| 476 | 劉度，合成臉 `D940` | 劉度，合成臉 `D563`（其餘相同） |

## 3. 劇本（`SINARIO.DAT`）

每個劇本 0x1800 bytes，依序是卡帶版的劇本 0–5，最後是黄巾の乱（選單第 0 個）。

| 位移 | 內容 |
|------|------|
| `+0x000` | 531 人 × 4 bytes（兵士/100、身分、忠誠、所在州；格式同卡帶版的 `SCEN_PERSON_PTRS` 指向的表） |
| `+0x84C` | 46 州 × 32 bytes（格式同卡帶版） |
| `+0xE0C`– | 未解：勢力（卡帶版 21 × 26 bytes 的格式對不上）、header 等；表尾是 22 bytes 的 extra 表與 13 × 2 bytes 的寶物持有者（黄巾の乱在 `0x14B2`） |

- 與卡帶版比：劇本 1–6 的人物只有 id 68 不同（賈範改成不登場；卡帶版劇本 4、5 的賈範有兵 1,900），州只有劇本 2 的第 12 州 +3 不同（44 → 45）。
- 黄巾の乱：529 人登場，君主有何進、韓馥、喬瑁、孔伷、公孫瓚、孫堅等。張角等黃巾軍首領不在人物表裡。
- 載入後的工作 RAM 版面和卡帶版的 `$FF0000` 相同，在 PRG-RAM `$78000`（人物 `$79562`＝`$78000 + 0x1562`）。

## 4. 頭像（`ORGKAO.DAT`）

| 格 | 內容 |
|------|------|
| 0–306 | 一般頭像 1–307，與卡帶版解壓後逐 byte 相同 |
| 307–617 | 預先合成的合成臉：碼 c 在合成臉碼表的第 k 個 → 格 307 + k |

- 碼表沒有的合成臉碼一律顯示第 307 格（表的第一個碼 `800C` 的臉）。碼表收的是卡帶版人物用到的 311 個碼（含 劉度 的舊碼 `D940`），CD 版改了 劉度 的碼 `D563` 卻沒有更新碼表，所以 CD 版的 劉度 實際顯示 `800C` 的臉（和 317 張虎同一張）。看起來是光榮的失誤。
- 311 格和卡帶版用部位疊出來的同碼合成臉比對：292 格相同；19 格（全部是類型 11）在 tile 13 或 18 不同。同一部位版本的 CD 版 tile 都一樣，所以是 CD 版重畫了類型 11 部位 0（上半）的版本 0、2、3 的 tile 13，與部位 1（下半）的版本 0、1、2 的 tile 18，不是合成錯誤。用到的人物（各一人）：尹賞、許汜、呉質、呉碩、向朗、孫朗、荀惲、尚挙、尚弘、薛瑩、陳琳、鄭度、董昭、楊洪、楊密、劉璝、劉先、呂範、冷苞。
- 調色盤與卡帶版相同；君主選擇畫面 8 張臉都用 CRAM line 3（調色盤 1），未逐張驗證畫面顏色。

## 6. kaodata

依 kaodata `docs/data-format.md` 的 `addedIn: "CD"`，併進 `san3-md`（`export_kaodata.py` 預設含 CD，`--no-cd` 不含；不含時與 kaodata 現有的 `san3-md` 逐位元相同）：

- 頭像 307–325：19 張重畫的合成臉（`addedIn: "CD"`，`code` 是合成臉碼）
- 何進：新 id 532，`addedIn: "CD"`，`note`「Mega-CD 版取代賈範（68）」，臉是合成臉 `8C93`（和賈範同碼）；68 仍是賈範
- `expressions`（`label`「Mega-CD 版」）：上面 19 人（CD 頭像），劉度（合成臉 `800C`，遊戲實際顯示的臉）；這 20 人的 `face` 加 `label`「卡帶版」
- 頭像 326：`D563`（CD 版劉度的人物資料指定、但碼表沒收而沒用到的臉，用卡帶版的部位畫），`group`「未使用」、`name`「劉度」、`addedIn: "CD"`，`note` 說明沒用到的原因
- `source.inputs` 加上 Track 01 的檔名與 SHA-1；`data/surnames.tsv` 加「何」

以上取捨已與使用者確認（2026-10-17）。
