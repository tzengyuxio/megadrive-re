# MD 信長の野望・武将風雲録 ROM 格式

ROM：`roms/Nobunaga no Yabou - Bushou Fuuunroku (Japan).zip`，1 MB，1991.OCT，KOEI。68000 C 編譯（`link`／`pea` 風格），資料一律**大端序**，沒有壓縮。資料內容與 SFC 版（`~/works/superfamicom-re/bushou/`）幾乎相同（劇本數值、頭像碼、組合臉區域表、戰場地形都一致），但結構改成 68000 的 C struct：欄位放寬成 16／32 bit，姓名直接放在武將記錄裡（SFC 是另一張姓名表）。

位址皆為 ROM 偏移（= 68000 位址）。RAM 寫成 `$FFxxxx`。

## 1. 文字與字型

| 項目 | 內容 |
|------|------|
| 文字碼 | 2 byte 大端：`0x8141 + g` = 字型第 g 字（g = 0–867）。**= SFC 碼 + 1**，字型順序、868 字的字元相同（`data/charset.txt` 直接沿用 SFC） |
| 跳脫 | 低位 byte 為 00 的碼不能存（00 = 結尾），寫成 `85F0／85F1／85F2` = `8200／8300／8400`（字 0xBF 熊、0x1BF 世、0x2BF 平；例：茶器「平野肩衝」） |
| 半形片假名 | 1 byte，cp932 `A1–DF` |
| 結尾 | `00`；字串區的字串以 `00` 結尾、再以 `FF` 補到偶數位址。`1B xx` 為控制碼（未逐一解） |
| 字型 | `0x50CA4` 起，每字 32 bytes，16×16 1bpp，8×8 四塊依 TL TR BL BR、每列 1 byte、MSB 在左；碼 c 的字在 `0x4E484 + 32 × (c − 0x8000)` |
| 外字 | 3、4 字姓用 1.5 字寬的拼字：`849C 849D 849E` 長宗我部、`849F 849D 849E` 香宗我部、`84A0 84A1` 鳥屋尾、`84A2 84A3` 佐々木（`rom.GAIJI`；前三組在武將姓名中出現過） |

868 字中只有第 867 字的點陣與 SFC 不同（外字區最後一字，沒看到使用處）。

畫面上，遊戲把字一個一個展開成 4bpp 寫進 VRAM（例：選大名確認訊息從 tile `0x200` 起，每字 4 tile）。

## 2. 劇本區塊

| 劇本 | 名稱 | ROM | 開局武將 | 登場武將表 |
|------|------|-----|----------|------------|
| 1 | 戦国の動乱（1555 年 3 月） | `0x473B8` | 250（0–249） | `0x45AC2`，120 筆 |
| 2 | 信長包囲網（1571 年 3 月） | `0x4B60E` | 255（0–254） | `0x468F0`，91 筆 |

選完劇本後 `0x50BA` 的 memcpy 把整塊（`0x4254` bytes）複製到 `$FF1000`（劇本 2 的位址參照在 `0xB312`）。區塊內的指標是 RAM 位址的低 16 bit：**區塊偏移 = 指標 − 0x1000**。

| 區塊偏移 | 大小 | 內容 |
|----------|------|------|
| `+0` | 3 | 劇本號、年 − 1476、月 |
| `+6` | 48 × 72 | 國 |
| `+0xD84` | 30 | 下一位登場武將（登場表格式，= 登場表第 0 筆的副本） |
| `+0xDA2` | 48 × 20 | 茶器 |
| `+0x1162` | 48 × 34 | 大名 |
| `+0x17C2` | 272 × 40 | 武將（RAM `$FF27C2`） |

| 26 | u32 | 町 |

### 2.2 茶器（20 bytes）

0–13 名稱、14 u16（`00FF`／`0000`，未解）、16 u16 持有者（武將指標，0 = 無）、18 u8 值（**未解**）、19 補位。

### 2.3 大名（34 bytes，48 格，空格的 +2 = 0）

| 偏移 | 內容 |
|------|------|
| 0 | u16 `00FF` |
| 2 | u16 大名本人的武將指標（0 = 空格） |
| 4–6 | 同盟大名編號（`FF` = 無） |
| 7–30 | 關係表，48 家 × 4 bit（自己 = F），意義**未解** |
| 31 | **未解**（多為 0x32） |
| 32 | **未解** |
| 33 | 大名編號；劇本 2 載入時重新編號（26 家不同） |

### 2.4 武將（40 bytes，272 格）

| 偏移 | 內容 |
|------|------|
| 0 | u16 `00FF`／`0000` |
| 2 | u16 同國下一位武將的指標（0 = 結尾） |
| 4 | 姓 7 bytes（文字＋00） |
| 11 | 名 7 bytes |
| 18 | 生年 − 1476 |
| 19–23 | 政治、戦闘、教養、魅力、野望 |
| 24 | **未解**（SFC 姓名表 byte 16；相性？） |
| 25–27 | 0 |
| 28 | u16 頭像碼（§3） |
| 30 | 旗標（**未解**） |
| 31 | **未解**（SFC byte 8） |

| 35 | 忠誠 |

劇本 1 的 250–254 是空格（頭像碼 `FFFF`），255、256 是遊戲執行時會改寫的暫存格。徳川家康／豊臣秀吉的改名沒有表，只出現在事件文字（`0x4401A` 徳川／家康、`0x4404A` 豊臣）。

### 2.5 登場武將（30 bytes，`00` 結尾）

0 登場年 − 1476、1 國（`FF` = 未定）、2 **未解**、3 姓 7、10 名 7、17 生年 − 1476、18–22 政 戦 教 魅 野望、23 **未解**（= 武將 +24）、24–25 0、26 u16 頭像碼、28 旗標、29 **未解**。結構推定自欄位對應，未在遊戲中等到武將登場。

## 3. 頭像

40×48 = 5×6 個 MD tile（4bpp，每列 4 bytes、高 nibble 在左），tile 列優先，一張 960 bytes。調色盤固定一組：`0x4F964`（國畫面 CRAM 調色盤 3；指標表 `0x5EC60`）。色 0 在畫面上透明。

- **專屬頭像**（碼 < `0x8000`）：`0x8EE68 + 960 × 碼`，有效 0–203（192–202 含女性；SFC 只有 180 張）。繪製程式 `0x793E`（`$FF6108` = 碼，VRAM tile `0x300 + 30 × slot`）。
- **沒有武將用的專屬頭像 180–203**（碼 `0xB4`–`0xCB`）：由事件程式直接指定。`0x7A64(x, y, 碼, 0)` 是畫頭像的進入點，下表依呼叫處與同畫面印的標籤判定（`export_kaodata.py` 的 `EXTRA_PORTRAITS`，名字直接讀這些 ROM 字串）：

  | 碼 | 頭像 | 依據 |
  |----|------|------|
  | `B4`–`B6` | 180–182 領民（同一人 3 種表情） | `$369DA`：碼 = `0xB4` + 表情參數，標籤「%s  領民」`0x43F66`；民心不滿、災害、豐凶等報告 |
  | `B7` `B8` `B9` `BA` `BC` `BE` | 183 山師、184 金山商、185 ヤミ商人、186 鉄砲鍛冶、188 越中富山ノ薬売リ、190 ルイス・フロイス | 來訪者表：名字指標 `0x5FDCE`、頭像碼 `0x5FE06`（以 `$FF63C0` 為索引，共 14 人，千利休、津田宗及、狩野永徳等其他 8 人是組合臉）；`BE` 也用在耶穌會事件 `0x3B5E6` |
  | `BB` | 187 鉄甲船造リ | `0x3F526`，同畫面標題「鉄甲船造リ」`0x45900` |
  | `BD` | 189 沢彦 | `0x39E24`，「政秀寺開山」「沢彦」`0x448B8` |
  | `BF` | 191 今井宗久 | `0x21894` 等 3 處，「堺 会合衆」「今井宗久」`0x41DDE` |
  | `C0`–`C9` | 192–201 姫 | `$77D6`：大名家的姫 = `0xC0` + 某值 mod 10 |
  | `CA` | 202 義姫 | `0x394D4`，「伊達家」「北ノ方」「義姫」`0x44492`；`$77D6` 對伊達家（+0x1A = 6）也回傳 `0xCA` |
  | `CB` | 203 畠山義継 | `0x38E2C`，「二本松城主」「畠山義継」`0x44204` |
- **組合臉**（bit 15 = 1）：程式 `0x7880`。`code & 0x1FFF`：bit 0–2 = 頭 h，bit 3–4 上、5–6 下、7–8 眼、9–10 鼻、11–12 口 的頁 p（0–3）。頁 (h, p) 是一張完整的 960 bytes 臉，在 `0xBEB68 + 960 × (4h + p)`（= 專屬索引 204 + 4h + p）。區域表 `0x5DB1E`，8 頭 × 11 個 u32：`[屬性 0x6000][上 起點 格數][下 …][眼 …][鼻 …][口 …]`，數值與 SFC `0x1793C` 相同（頭 0：0,20 / 20,10 / 10,3 / 15,3 / 21,2）。依 上→下→眼→鼻→口 的順序從各自的頁複製連續的格到 `$FF9CB0`，後面覆蓋前面，再 DMA 到 VRAM。

## 4. 調色盤

`0x4F904` 起每 32 bytes 一組：`0x4F904` 地圖（CRAM 0）、`0x4F924`、`0x4F944`、`0x4F964` 頭像（CRAM 3）、`0x4F984` 國畫面（CRAM 0）。MD 色 9 bit（bit 1–3 R、5–7 G、9–11 B）。轉 8 bit 時用 MAME 的 DAC 階 `[0, 52, 87, 116, 144, 172, 206, 255]`（`rom.LEVELS`），匯出的 PNG 才會和 MAME 截圖逐 pixel 相同。

## 5. 大地圖（選大名畫面）

VDP：plane A／B／window 都在 `0xE000`，平面 32×128（reg 16 = 0x30），VSRAM A = 0、B = 0x100（plane B 從第 32 列起），H32，hscroll `0xD800`，SAT `0xDC00`（只有游標）。

- Plane B = 地圖：tilemap 30 欄 × 28 列（大端 word）`0x835A0`，畫在 plane B 第 1 欄起；CHR 429 tile `0x80000` → VRAM tile `0x3FC`；調色盤 `0x4F904`；色 0 透明（顯示背景色）。
- Plane A：年月、訊息、各國的家紋。這張圖沒有勢力上色。

## 6. 戰場

| 項目 | ROM | 內容 |
|------|-----|------|
| 野戰地圖 | `0x57904` | 48 × 154 bytes（14×11，國順序），程式參照 `0x323C8` |
| 城地圖 | `0x5984C` | 49 × 143 bytes（13×11；第 48 張 = 安土城），程式參照 `0x3108E` |
| 城第二層 | `0x5B558` | 同上形狀，**未解** |
| 野戰名 | `0x5ED00` | 49 個 u32 指標（第 48 = 空） |
| 城名 | `0x5EDC4` | 50 個 u32 指標（含安土城、岐阜城），字串在 `0x40Dxx–0x4100E` |
| 天氣 | `0x5EC9C` | 晴 曇 雨 雪 |
| 指令名 | `0x5ECAC` | 移動 攻撃 待機 退却 情報 伝令 委任 |

三份地形資料與 SFC（`0x3746A`、`0x393B2`、`0x3B0BE`）逐 byte 相同。依 SFC 的規則：奇數欄下錯半格，地形 7 平地、8 丘陵、9 林、B 海湖、C 山、D 川。**MD 的戰場畫面組裝（metatile、CHR、調色盤）未解**，`export.py` 只輸出地形值示意圖。

## 9. 未解部分

- 國 +2、+42/+44（載入時改寫，可能是計算值）、+68、相鄰的高 2 bit。
- 大名關係表（4 bit 的意義）、+31、+32。
- 武將 +24、+30（旗標）、+31、+32；登場武將 +2、+23、+29。
- 茶器的值（+18）與 +14。
- `1B xx` 文字控制碼、外字第 867 字。
- MD 戰場畫面（野戰／城）的繪製：metatile 表、CHR、調色盤；城第二層的意義。
- 季節調色盤、家紋圖、勢力地圖上色（大地圖本身沒有上色）。
- 登場武將表沒有在遊戲中等到實際登場驗證。
