# 三国志列伝 ROM 格式

1MB，無壓縮的 68000 程式＋資料。位址皆為 ROM offset（＝68000 位址）；RAM 位址寫成 `$FFxxxx` 或省略高位的 `$xxxx`。多 byte 數值皆 big-endian。

§1–§8 為日版位址；中文版（三國志列傳 亂世群英）是同一套程式與資料搬移位置後換字型，位址對照見 §9。

## 1. 文字

- **字型** `0x812B8`：16×16 1bpp，每字 32 bytes（每列一個 word），968 字。轉寫在 `data/charset.txt`。
- **字碼**：16-bit，字號＝高 byte×64＋低 byte（低 byte 只用 0–63）。全形空白＝字號 63（`$003F`）。
- 轉寫保留 ROM 本身的誤字／異體：形道栄、下丕、陸積、許緒等照錄。
- **小字型** `0x88BB8`：8×8 1bpp，每字 8 bytes；讀音用，字號 1–71 對應 `rom.KANA`，0＝結束。

## 2. 名稱表

| 位址 | 內容 |
|------|------|
| `0x89BAE` | 人物名 256 × 3 字（6 bytes），五十音序；人物號＝頭像號 |
| `0x8A2AE` | 讀音 256 × 8 bytes（小字型字號） |
| `0x897FC` | 城名 40 × 2 字 |
| `0x89B72` | 武器名：槽 s（0–2）值 v（1–3）在 `+s*0x12+v*6`，3 字 |
| `0xB93E` | 武器加成，依值 0–3：0／15／25／35（狀態畫面取三槽最大） |
| `0xD584A` | 城座標 40 × (x, y) word，大地圖像素座標（`$674DC` 讀，sprite 用 y−0x10） |

## 3. 劇本

`0x3E1C`：3 個 long 指標 → 各劇本目錄（189 年 `0x8AAAE`、200 年 `0x8D42A`、215 年 `0x8FDA6`），每個目錄 33 個 long 指標。載入程式 `$3E28` 依序把每表複製到 RAM（`$3FF8` rts）。表的順序、RAM 位址、大小見 `rom.SCENARIO_TABLES`：

| RAM | 大小 | 型別 | 意義 |
|-----|------|------|------|
| `F428` | 40 | byte | 城的勢力（0xFF 無） |
| `F460` | 80 | word | 城的太守（0xFFFF 無） |
| `E640` | 32 | word | 勢力的君主 |
| `E000`／`E0A0`／`E140`／`E1E0` | 160 | long | 城：金、米、民／1000、産業値 |
| `E280`／`E320`／`E3C0`／`E460`／`E500`／`E5A0` | 160 | long | 城：**未解** |
| `B000`／`B200` | 512 | word | 體力上限、體力 |
| `B400`／`B600`／`B800` | 512 | word | 武力、知力、統率力 |
| `BA00`／`BC00` | 512 | word | **未解** |
| `BE00`／`C000` | 512 | word | 文官値、武官値 |
| `C200`／`C300`／`C400`／`C500` | 256 | byte | 徳（畫面上限 100，`$B7A4`）、忠誠度、機動力、士氣 |
| `C600` | 256 | byte | 等級；0xFF＝本劇本不登場 |
| `C700` | 256 | byte | 官位碼（4＝君主；bit 4 顯示額外稱號）——完整對照**未解** |
| `C800` | 1024 | long | 兵力 |
| `CC00` | 256 | byte | 所在城（1-based，0＝無） |
| `E710` | 32 | word | **未解**（每勢力一個） |
| `EA88` | 768 | 3 byte | 武器 3 槽；ROM 存 槽1, 槽0, 槽2，載入時交換前兩個 |
| `F000` | 512 | word | **未解**；ROM 存 word，載入成 byte 值−0xB8（0xFFFF→0xFF） |

狀態畫面的兩個攻撃力：攻撃力1＝武力×士氣／100（`$B8B8`），攻撃力2＝武力＋武器加成（`$B8E2`）。

注意：開局後遊戲會微調等級 ±1，電腦勢力行動也會改金、城等，所以驗證時在 `$3FF8`（載入完成）比對 RAM。

## 4. 頭像

畫頭像的程式 `$65C22`（D0＝人物號）。48×64 像素＝6×8 tile。

| 位址 | 內容 |
|------|------|
| `0xAF11A` | 256 × 48 個 tile 號（word），列優先 |
| `0xB511A` | 眼：每人 8 words（開 4、閉 4），4×1 sprite 疊在 tile (1,3)；座標寫死在 `$23CA`；色 0 透明 |
| `0xB611A` | 嘴：每人 4 words（閉 2、開 2），取代 nametable (2,5)(3,5) |
| `0xB711A` | 256 bytes：調色盤號 |
| `0xB671A` | 調色盤，每組 16 色（MD 色 word `0000BBB0GGG0RRR0`） |
| `0xB721A` | 4bpp tile，32 bytes |

MD 色轉 RGB 用 MAME 色階 0, 52, 87, 116, 144, 172, 206, 255。

## 5. 圖塊壓縮（`$AD48`）

word 串流直接寫進 VDP data port，參數為來源、字典、字數−1：

- `< $FE00`：原樣輸出
- `$FEnn`：輸出字典第 nn 項（字典＋4×nn 的 2 words；若第一個 word 本身是 `$FExx`，只輸出它）
- `$FFnn`：下一個 word 重複 nn＋1 次（下一個是字典參照時取其第一個 word，第二個 word 接著輸出）

實作：`rom.unpack_words`。

## 6. 大地圖

- 表頭 `0x81276`（`$AEB0` 讀）：word 塊列數（4）、byte 塊高（24 列）、byte 塊寬（40 tile）、long 基址，再來每塊一個 word 偏移（0xFFFF 結束），塊順序＝y 塊×4＋x 塊。共 4×6 塊 → 160×144 tile。
- 每塊：long 資料指標＋25 個 word 偏移（24 列＋結尾）。列內 word 的 (w & 0x7FF) − 0x6FF＝n ≥ 0 時，下一 word 重複 n & 0x7F 次，bit 7 設時每次 +1。
- 遊戲可捲動的寬度是 144 tile。
- 調色盤 `0x81B6`：4 組 × 16 色（第 1 組 entry 9、12 執行時會變，原因未查）。
- 圖塊：3 段 `$AD48` 串流（與 VRAM 完全一致），`$A1B2` 載入：

| 串流 | 字典 | 字數 word | 起始 tile |
|------|------|-----------|-----------|
| `0xCF39E` | `0xCF21A` | `0xD4242` | 0x000 |
| `0xD211E` | `0xD2076` | `0xD4248` | 0x200 |
| `0xD0862` | `0xD0792` | `0xD4244` | 0x400 |

## 7. 驗證用操作序列

- 開機到設定畫面：`w900 start:10 w120` 後 5 次 `c:10 w200`；`down:6 w30`×n 選第 n 個劇本；之後的確認序列見 `verify_scenarios.SETTINGS`。
- 狀態畫面（劉備被選中）：`verify_faces.BOOT[版本]`；再 `down:6 w30` 移到関羽。中文版第一回合開始較慢，等待 `w1500` 改 `w2100`（日版用 `w2100` 反而會差一步，所以分版本）。
- MAME savestate 重播（`tools/replay.py`）讓每個頭像／人物只需從存檔點跑幾十 frame。

## 9. 中文版（San Guo Zhi Lie Zhuan - Luan Shi Qun Ying (China)）

同表頭（`GM G-5510`、1MB），標題畫面「三國志列傳 亂世群英」。程式幾乎相同，只是整段位移（例：`$80E4`→`$8112`、`$A1B2`→`$A1E0`、`$AD48`→`$ADFC`）；資料表內容與日版逐 byte 相同（劇本 33 表、頭像各表、地圖 stream／字典、城座標、地圖色盤），只換了字型與文字。`rom.layout(rom)` 依 `0x9D6` 的 long（`lea` 人物名表的運算元：日版 `0x89BAE`、中文版 `0x8A504`）選位址組。

| 項目 | 日版 | 中文版 |
|------|------|--------|
| 字型（16×16） | `0x812B8`，968 字 | `0x8159C`，1034 字（`data/charset_cn.txt`） |
| 人物名 | `0x89BAE` | `0x8A504` |
| 讀音 | `0x8A2AE`（小字型 `0x88BB8`） | 無（狀態畫面不顯示讀音） |
| 城名 | `0x897FC` | `0x8A216` |
| 武器名／加成 | `0x89B72`／`0xB93E` | `0x8A4C8`／`0xB9DE` |
| 劇本目錄指標／載入程式／rts | `0x3E1C`／`$3E28`／`$3FF8` | `0x3E48`／`$3E54`／`$4024` |
| 劇本目錄 | `0x8AAAE`、`0x8D42A`、`0x8FDA6` | `0x8AC04`、`0x8D580`、`0x8FEFC`（各表指標 +0x156） |
| 頭像表起點（`FACE_MAP`，其餘表相對位移相同） | `0xAF11A` | `0xAE39A`（整體 −0xD80） |
| 畫頭像程式 | `$65C22` | `$661D4` |
| 大地圖表頭／色盤 | `0x81276`／`0x81B6` | `0x8155A`／`0x81E4` |
| 地圖 tileset（stream, 字典, 字數） | `0xCF39E`…（§6） | `(0xCE61E, 0xCE49A, 0xD34C2)`→0x000、`(0xD139E, 0xD12F6, 0xD34C8)`→0x200、`(0xCFAE2, 0xCFA12, 0xD34C4)`→0x400 |
| 城座標 | `0xD584A` | `0xD4ACA` |

- **字碼制同日版**（字號＝高 byte×64＋低 byte，全形空白＝63）。1034 字中 651 字與日版 bitmap 相同（多數同字號；日版 0–56 的假名區在中文版換成漢字），其餘 383 字以字型比對輔助後逐字目視轉寫。
- 文字改成繁體字形（關羽、張遼、薊縣…），武器名也改了（青釭劍、雁翎刀、偃月刀…）。字型本身的誤字照錄：臨淄→**臨溜**、潘璋→**滔璋**、韓遂→**韓逐**；高幹→高干、蔣幹→蔣干。字號 810 與 1025 都是「畫」；40「決」與 733「决」字形不同。
- 武官値等狀態畫面欄位、數字 tile、版面與日版相同（`verify_persons.py` 不需改位置）。
