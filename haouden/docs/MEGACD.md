# Mega-CD 版『信長の野望・覇王伝』

KOEI，Mega-CD（系統區 `(C)T-76 1994.FEB`、序號 `GM T-76024 -00`；卡帶版是 1993.DEC）。映像：`roms/megacd/Nobunaga no Yabou - Haouden (Japan).7z`（Redump，Track 01 MODE1/2352＋音軌）。程式碼在 `cd.py`：`Disc` 繼承 `rom.Rom`，換上光碟的表格與檔案，沿用卡帶版的解碼器。

和卡帶版相比：

- 多了第 4 個劇本 1583 年（385 人開局、52 人後登場；人物全是卡帶版既有的 id 與姓名）
- 28 個卡帶版用組合臉的人物改用新的專屬頭像（348–375）
- 前 3 個劇本的人物、城、大名、後登場人物與卡帶版完全相同（只有 RAM 指標換成 PRG-RAM 位址）
- 頭像改成未壓縮；組合臉的部位仍是卡帶版的 LZ 串流

## 2. 表格（`SMAIN.PRG` 內的位移）

| 表 | CD | 卡帶版 | 說明 |
|------|------|------|------|
| 頭像表 1 | `0x419A4` | `0x728E0` | face id 0xD3–0x36D 每個一個 word；28 筆從組合碼改成 `0x8150`–`0x816B`（專屬頭像 348–375） |
| 頭像表 2 | `0x41B02` | `0x72A3E` | 內容相同 |
| 頭像調色盤 | `0x2DDF4` | `0x5EE22` | 內容相同 |

face id 的分段（0xD3 以下直接是專屬頭像 id + 12 等，見 ROM_FORMAT.md）與卡帶版相同，由模擬器驗證全部 927 個 face id 確認。

改用新頭像的 28 人（face id → 專屬頭像）：相良頼房、薄田兼相、三村家親、三村元親、明石全登、吉良親貞、籾井教業、前田慶次、豊臣秀次、豊臣秀頼、塙直之、本多正純、本荘繁長、上条政繁、里見義頼、畠山義慶、姉小路頼綱、徳川信康、徳川秀康、徳川秀忠、細川忠興、山名祐豊、吉川広家、河野通直、山内一豊、真田大助、中山信正、秋田実季（依 id 順，頭像 348–375）。

## 3. 劇本

選單是 1551、1568、1582、1583。選劇本後 `SAVEDAT<n>.DAT` 原樣放到 PRG-RAM `$78000`（卡帶版 `$FF0000` 的版面），1582 與 1583 另把 `+0x72A5` 的 bit 6 設起來（卡帶版只對 1582 這樣做）。

## 4. 驗證（Genesis Plus GX，`tools/gpgx.py`）

| 腳本 | 內容 | 結果 |
|------|------|------|
| `verify_cd_faces.py` | 同卡帶版 `verify_faces.py`：1551、1 人、選大名畫面游標在龍造寺隆信；把每個 face id 寫進他的記錄（PRG-RAM `$78000` 起的人物格 4 +34）後按 C，比對 VRAM `$4000` 起 960 bytes 與 CRAM 第 1 列 | 專屬 376/376（新頭像 28）、組合 551/551、調色盤 OK，約 50 秒 |
| `verify_cd_scenarios.py` | 選 4 個劇本，在「何人でプレイしますか」比對 PRG-RAM `$78000` 起 0x7476 bytes 與 `SAVEDAT1`–`4.DAT` | 4 劇本全部 29,814 bytes 一致（含 `+0x72A5` 的修正），約 3 秒 |

`TAIKI.DAT` 的後登場人物沒有在模擬器裡驗證（前 3 串與卡帶版逐筆相同）。

## 5. kaodata

依 kaodata `docs/data-format.md` 的 `addedIn: "CD"`，併進 `nobu5-md`（`export_kaodata.py` 預設含 CD，`--no-cd` 不含；不含時與 kaodata 現有的 `nobu5-md` 逐位元相同）：

- 專屬頭像 348–375：新增的 28 張（`addedIn: "CD"`，都有人用，沒有 `group`）
- 上面 28 人保留卡帶版的組合臉，CD 頭像放進 `expressions`，`label`「Mega-CD 版」
- 沒有新人物（1583 年劇本的人物全是既有的 id 與姓名）
- `source.inputs` 加上 Track 01 的檔名與 SHA-1
